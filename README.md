# Departamento de informática

Documentación de procedimientos del departamento de informática.
Todo el contenido de este repositorio es ficticio y se usa con fines formativos.

## Estructura

- `documentacion/`: información general del departamento.
- `procedimientos/`: procedimientos técnicos, uno por archivo.
- `inventario/`: inventario de equipos.

## Cómo contribuir

1. Haz un fork de este repositorio.
2. Crea una rama para tu tarea (`feature/...`).
3. Sigue el formato de `procedimientos/altas-usuarios.md`.
4. Abre un pull request enlazado con el issue correspondiente (`Closes #N`).
