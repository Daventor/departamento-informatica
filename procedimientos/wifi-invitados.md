# Procedimiento de wifi invitados

## 1. Objetivo
Crear una wifi para invitados

## 2. Responsables
Técnico de redes; supervisa el responsable del departamento.

## 3. Frecuencia o momento
A la llegada de un nuevo invitado.

## 4. Pasos
1. Recibir la solicitud de alta para un nuevo invitado.
2. Configurar red de invitados para este nuevo usario.
3. Entregar las credenciales por un canal seguro.

## 5. Registro
Anotar el alta en el registro de wifi de invitados.
